Trainiert den Assistentenpfad
[Modell (Übertragungsfunktion)](../coefficients-only.mdx#model-transfer-function) — für Sensoren,
die mit einem Kalibrierzertifikat ankommen, das das Kalibriermodell direkt angibt, ohne rohe
Referenz-/Messdatenpunkte, die neu angepasst werden könnten.

## 4.0 Einrichtung

**Anlage** (Anlagen → Neue Anlage):

| Feld | Wert |
|---|---|
| Name | External Pressure Transmitter |
| Hersteller / Modell | beliebig, z. B. WIKA / A-10 |
| Anlagentyp | sensor |

Ein Kanal:

| Feld | Wert |
|---|---|
| Kanal-ID | CH1 |
| Physikalische Größe | Druck |
| Bereich Min / Max | 0 / 1000 |
| Einheit | kPa |
| Genauigkeit | ±0,5 kPa (absolut) |

Die Genauigkeitsspezifikation ist das, wogegen die Konformitätsprüfung von Modell direkt angegeben
vergleicht — siehe unten.

## 4.1 Assistent — Schritt 1 (Allgemeine Informationen)

| Feld | Wert |
|---|---|
| Kalibrierart | Externes akkreditiertes Labor |
| Kalibrieranbieter | Any Cal Lab Inc. |
| Zertifikatsnummer | ACL-2026-00842 |

## 4.2 Assistent — Schritt 2 (Eingabedaten)

Schritt 2 beginnt mit einem Methoden-Selektor. Die Wahl von **Modell (Übertragungsfunktion)**
tauscht den Rest des Schritts von der Rohdaten-Eingabe zu einem Modell-Eingabeformular.

Das Zertifikat gibt an: *Referenz ≈ 1,0025 × Messwert − 0,42 kPa, gültig 0–1000 kPa, erweiterte
Unsicherheit des Referenznormals ±0,5 kPa (k=2)*.

| Feld | Wert |
|---|---|
| Modelltyp | Polynom |
| Polynomordnung | 1 |
| Koeffizient (× x) | 1,0025 |
| Koeffizient (Konstante) | −0,42 |
| Gültiger Bereich min. | 0 |
| Gültiger Bereich max. | 1000 |

Die Gleichungsvorschau zeigt: $f(x) = 1.0025x - 0.42\ \text{(kPa)}$.

## 4.3 Assistent — Schritt 3 (Überprüfung) und was gespeichert wird

Auch ohne Rohdaten sammelt Schritt 3 dieselben
[Unsicherheitsbudget](../uncertainty-budget.mdx)-Eingaben, die auch eine Kalibrierung mit Rohdaten
sammelt:

| Feld | Wert |
|---|---|
| U des Referenznormals (manuell) | 0,5 |
| k des Referenznormals | 2 |
| Entscheidungsregel | Guard-Band-Annahme |

Im Hintergrund wertet der Assistent zwei synthetische Nullfehler-Punkte am deklarierten gültigen
Bereich (0 und 1000 kPa) über dieselbe Analyse-Pipeline aus, die auch Rohdaten verwenden, wobei die
Anpassung übersprungen wird — dies kombiniert das obige Typ-B-Budget (hier nur den Term des
Referenznormals) und wendet die Entscheidungsregel an, wobei das Modell exakt wie deklariert als
vertrauenswürdig behandelt wird. Beim Speichern:

- `poly_order = 1`, `poly_coefficients = [1.0025, -0.42]`, `range_min = 0`, `range_max = 1000`,
  `valid_range_min = 0`, `valid_range_max = 1000`.
- `uncertainty_budget` enthält eine Typ-B-Zeile (`reference_standard`, Standardunsicherheit
  `0.5 / 2 = 0.25` kPa) — die Typ-A-Zeile (`fit_residuals`) ist vorhanden, aber exakt `0`, da das
  Modell wie deklariert als vertrauenswürdig behandelt wird.
- `combined_uncertainty ≈ 0.25` kPa, `expanded_uncertainty ≈ 0.49` kPa (k≈1,96 bei 95 %
  Konfidenz, Normalverteilung).
- `r_squared`, `rmse`, `max_error` und `non_linearity` sind allesamt **null** — es gibt keine
  echten Messdaten, aus denen sie abgeleitet werden könnten (siehe
  [Alternative Dateneingabemodi für Kalibrierungen](../coefficients-only.mdx)).
- `decision_rule = "guard_band_w_uncertainty"` und eine echte `conformity_statement`: Die
  Akzeptanzzone wird durch die erweiterte Unsicherheit nach innen verkleinert
  (`0.5 - 0.49 ≈ 0.01` kPa verbleibende Marge), sodass dieser Datensatz **KONFORM** ist — knapp,
  was genau veranschaulicht, wofür Guard Banding da ist.
