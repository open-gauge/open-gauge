## Die Rechnung

Anpassung (Grad 1, alle 12 Punkte): $a = 0{,}99833$, $b = -0{,}76668$.

Maximalfehler = **0,863215 N**, bei Punkt 11 (Referenz 100 N, Messwert 101,8 N) → %FS-Fehler =
$0{,}863215/500 \times 100\% = \mathbf{0{,}1726\%}$.

**Hysterese** — Open Gauge gruppiert Punkte nach Referenzwert und nimmt die größte Streuung der
Messwerte innerhalb jeder Gruppe, in der sich der Referenzwert wiederholt und sowohl ein
aufsteigendes als auch ein absteigendes Segment vorhanden ist:

| Referenz | Messwerte bei dieser Referenz | Spanne |
|---|---|---|
| 0 N | 0,2, 0,3, 1,0 | 0,8 |
| 100 N | 100,6, 101,8 | 1,2 |
| 200 N | 200,9, 201,9 | 1,0 |
| 300 N | 301,0, 301,7 | 0,7 |
| 400 N | 401,1, 401,6 | 0,5 |

Größte Spanne = **1,2 N** (bei 100 N) → **Hysterese = 1,2**.

**Wiederholbarkeit** — nur bei 0 N gibt es 3 oder mehr Messungen (0,2, 0,3, 1,0):

$$
\bar{x} = \frac{0.2 + 0.3 + 1.0}{3} = 0.5, \qquad
s^2 = \frac{(0.2-0.5)^2 + (0.3-0.5)^2 + (1.0-0.5)^2}{3-1} = \frac{0.09+0.04+0.25}{2} = 0.19
$$

$$
\text{repeatability} = \sqrt{0.19} = 0.435890\ \text{N}
$$

**Unsicherheitsbudget:**

| Quelle | u |
|---|---|
| fit_residuals (Typ A, dof = 10) | 0,487526 |
| resolution (Typ B) = $0{,}2/\sqrt{12}$ | 0,057735 |

- Kombiniert: $u_c = \sqrt{0.487526^2 + 0.057735^2} = \mathbf{0{,}490933\ N}$.
- $\nu_{\text{eff}} \approx \mathbf{10{,}3}$.
- Erweiterungsfaktor $k = \Phi^{-1}(0.975) \approx 1{,}96$ (aus Vertrauensniveau 95 %, nicht
  eingegeben).
- Erweitert: $U = 0{,}490933 \times 1{,}96 = 0{,}962211 \approx \mathbf{0{,}96\ N}$
  (2 signifikante Stellen).

**Entscheidungsregel — beide ausprobieren und vergleichen.** Die Genauigkeitsspezifikation ist
±0,15 % FS, sodass die Toleranz über den gesamten Bereich konstant ist:
$\text{tolerance} = 0{,}0015 \times 500\ \text{N} = 0{,}75\ \text{N}$. Der größte Fehler des
Durchlaufs (0,863215 N, bei Referenz 100 N) überschreitet diese:

| Entscheidungsregel | Prüfung (Maximalfehler = 0,863215, Toleranz = 0,75) | Ergebnis |
|---|---|---|
| Einfache Annahme | $0{,}863215 \le 0{,}75$? Nein | **NICHT KONFORM** |
| Geteiltes Risiko (+U) | $0{,}863215 - 0{,}962211 = -0{,}098996 \le 0{,}75$ | **KONFORM** |

Dies ist ein wirklich realistischer Fall: eine Wägezelle, deren roher Fehler ihre enge
±0,15-%-FS-Spezifikation überschreitet, deren gesamte Messunsicherheit aber groß genug ist, dass
Labor und Kunde unter einer Geteiltes-Risiko-Regel übereinstimmen, dass sie dennoch akzeptabel ist.
Ein guter Test sowohl für "echte Fehlschläge kommen vor" als auch für "die gewählte Regel verändert
das Ergebnis".
