ascendente/descendente, el detector de [repetibilidad](../curve-fitting.mdx#repeatability) de
puntos triplicados, y otra divergencia entre aceptación simple y riesgo compartido.

## Las matemáticas

Ajuste (grado 1, los 12 puntos): $a = 0.99833$, $b = -0.76668$.

Error máximo = **0.863215 N**, en el punto 11 (referencia 100 N, medido 101.8 N) → error %FS =
$0.863215/500 \times 100\% = \mathbf{0.1726\%}$.

**Histéresis** — Open Gauge agrupa los puntos por valor de referencia y toma la mayor dispersión de
valores medidos dentro de cualquier grupo donde el valor de referencia se repite con un segmento
tanto ascendente como descendente presente:

| Referencia | Valores medidos en esta referencia | Intervalo |
|---|---|---|
| 0 N | 0.2, 0.3, 1.0 | 0.8 |
| 100 N | 100.6, 101.8 | 1.2 |
| 200 N | 200.9, 201.9 | 1.0 |
| 300 N | 301.0, 301.7 | 0.7 |
| 400 N | 401.1, 401.6 | 0.5 |

Mayor intervalo = **1.2 N** (en 100 N) → **histéresis = 1.2**.

**Repetibilidad** — solo 0 N tiene 3 o más lecturas (0.2, 0.3, 1.0):

$$
\bar{x} = \frac{0.2 + 0.3 + 1.0}{3} = 0.5, \qquad
s^2 = \frac{(0.2-0.5)^2 + (0.3-0.5)^2 + (1.0-0.5)^2}{3-1} = \frac{0.09+0.04+0.25}{2} = 0.19
$$

$$
\text{repeatability} = \sqrt{0.19} = 0.435890\ \text{N}
$$

**Presupuesto de incertidumbre:**

| Fuente | u |
|---|---|
| fit_residuals (Tipo A, dof = 10) | 0.487526 |
| resolution (Tipo B) = $0.2/\sqrt{12}$ | 0.057735 |

- Combinada: $u_c = \sqrt{0.487526^2 + 0.057735^2} = \mathbf{0.490933\ N}$.
- $\nu_{\text{eff}} \approx \mathbf{10.3}$.
- Factor de cobertura $k = \Phi^{-1}(0.975) \approx 1.96$ (a partir de Confianza 95%, no ingresado).
- Expandida: $U = 0.490933 \times 1.96 = 0.962211 \approx \mathbf{0.96\ N}$ (2 cifras
  significativas).

**Regla de decisión — prueba ambas y compara.** La especificación de exactitud es ±0.15% FS, así que
la tolerancia es constante a lo largo del rango: $\text{tolerance} = 0.0015 \times 500\ \text{N} =
0.75\ \text{N}$. El mayor error del barrido (0.863215 N, en referencia 100 N) supera eso:

| Regla de decisión | Comprobación (error máximo = 0.863215, tolerancia = 0.75) | Resultado |
|---|---|---|
| Aceptación simple | $0.863215 \le 0.75$? No | **NO CONFORMA** |
| Riesgo compartido (+U) | $0.863215 - 0.962211 = -0.098996 \le 0.75$ | **CONFORMA** |

Este es un caso genuinamente realista: una celda de carga cuyo error en bruto supera su
especificación ajustada de ±0.15% FS, pero cuya incertidumbre de medición global es lo
suficientemente grande como para que, bajo una regla de riesgo compartido, el laboratorio y el
cliente acuerden que sigue siendo aceptable. Una buena prueba tanto de que "los fallos reales
ocurren" como de que "la regla que elijas cambia el resultado."
