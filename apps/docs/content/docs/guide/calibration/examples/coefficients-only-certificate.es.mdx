Ejercita la ruta del asistente de [solo coeficientes](../coefficients-only.mdx) — para
sensores que llegan con un certificado de calibración que indica el polinomio de calibración
directamente, sin puntos de datos de referencia/medido en bruto que reajustar.

## 4.0 Configuración

**Activo** (Activos → Nuevo activo):

| Campo | Valor |
|---|---|
| Nombre | External Pressure Transmitter |
| Fabricante / Modelo | cualquiera, p. ej. WIKA / A-10 |
| Tipo de activo | sensor |

Un canal:

| Campo | Valor |
|---|---|
| ID de canal | CH1 |
| Magnitud física | Presión |
| Rango mín / máx | 0 / 1000 |
| Unidad | kPa |

No se necesita nada más — una calibración de solo coeficientes no consulta la exactitud, la
resolución, ni la incertidumbre de medición (no se ejecuta ningún análisis en el que incorporarlas).

## 4.1 Asistente — Paso 1 (Información general)

| Campo | Valor |
|---|---|
| Tipo de calibración | Externa |
| Proveedor de calibración | Any Cal Lab Inc. |
| Número de certificado | ACL-2026-00842 |
| Solo coeficientes (sin datos en bruto) | **marcado** |

Marcar la casilla cambia el Paso 2 del ingreso de datos en bruto a un formulario de ingreso de
coeficientes, y el indicador de paso cambia su etiqueta a "Coeficientes" / "Revisión" en lugar de
"Datos en bruto" / "Análisis".

## 4.2 Asistente — Paso 2 (Coeficientes)

El certificado indica: *referencia ≈ 1.0025 × medido − 0.42 kPa, válido 0–1000 kPa, incertidumbre
expandida ±1.2 kPa (k=2)*.

| Campo | Valor |
|---|---|
| Orden del polinomio | 1 |
| Coeficiente (× x) | 1.0025 |
| Coeficiente (Constante) | −0.42 |
| Rango válido mín | 0 |
| Rango válido máx | 1000 |
| Incertidumbre indicada en el certificado | **marcado** |
| Incertidumbre expandida (±) | 1.2 |
| Factor de cobertura k | 2 |

La vista previa de la ecuación muestra: $f(x) = 1.0025x - 0.42\ \text{(kPa)}$.

## 4.3 Asistente — Paso 3 (Revisión) y qué se guarda

No hay ningún análisis que ejecutar, así que el Paso 3 repite la ecuación, el rango válido y la
incertidumbre declarada para una comprobación final antes de guardar. Al guardar:

- `poly_order = 1`, `poly_coefficients = [1.0025, -0.42]`, `range_min = 0`, `range_max = 1000`,
  `valid_range_min = 0`, `valid_range_max = 1000`.
- `expanded_uncertainty = 1.2`, `coverage_factor = 2`,
  `combined_uncertainty = 1.2 / 2 = 0.6`.
- `uncertainty_budget = [{ source: "external_certificate_stated", value: 1.2, divisor: 2,
  standard_uncertainty: 0.6, ... }]` — una sola fila, no descompuesta en partes Tipo A/B, ya que
  el certificado solo da una cifra global.
- `r_squared`, `rmse`, `standard_error`, `max_error`, `decision_rule`, y
  `conformity_statement` son todos **nulos** — sin datos en bruto no hay ningún ajuste que
  puntuar ni ningún error evaluado contra el cual comprobar una especificación, así que Open Gauge
  no muestra una insignia de CONFORMA/NO CONFORMA para este registro (consulta
  [Calibraciones de solo coeficientes](../coefficients-only.mdx)).
