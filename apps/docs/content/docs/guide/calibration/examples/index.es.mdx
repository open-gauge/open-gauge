title: Ejemplos resueltos
description: Cuatro ejemplos de calibración completamente resueltos que puedes replicar a través de la interfaz para verificar el motor de cálculo de Open Gauge.
---

Cuatro ejemplos de calibración completamente resueltos, cada uno ejercitando una parte diferente del
motor de calibración de Open Gauge. Cada número en ellos fue producido ejecutando el código real de
producción contra los datos de entrada mostrados, y luego rederivado de forma independiente a mano a
partir de las fórmulas subyacentes para confirmar que coinciden. Si ingresas la misma configuración de
activo/canal y los mismos puntos de datos a través de la interfaz, deberías ver los mismos números —
consulta [Redondeo](./rounding-and-troubleshooting.mdx) para las reglas de precisión de
visualización.

Lectura de referencia: [Calibración](../overview.mdx) para saber qué significa cada número y por qué,
[Normas y glosario](../../reference/standards-glossary.mdx) para las cláusulas del GUM/ISO 17025 que
implementan estas fórmulas.
