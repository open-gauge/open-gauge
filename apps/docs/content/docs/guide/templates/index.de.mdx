Eine **Dokumentvorlage** ist ein wiederverwendbares Layout für ein druckbares Dokument — ein
Kalibrierzertifikat oder ein Kalibrierverfahren — einmal gestaltet und bei jeder Erstellung mit
echten Daten befüllt. Verwalten Sie sie über **Admin-Panel → Vorlagen**, zusammen mit von Hand
erstellten LaTeX-Zertifikatsvorlagen (siehe
[Zertifikatsvorlagen](../calibration/certificate-templates.mdx)) — die Schaltfläche **„Neue
Vorlage"** dieses Bereichs öffnet ein Modal mit drei Optionen, und „Neue Vorlage erstellen" ist
diejenige, die diesen Editor für eine leere Vorlage öffnet; Export/Import und Erzeugung werden
weiter unten unter [PDF-Erzeugung](#pdf-erzeugung) beschrieben.

## Zwei Vorlagentypen

- **Kalibrierzertifikat** — stellt Variablen zu Anlage, Kalibrierung, Messwerten,
  Koeffizienten/Statistiken, Messunsicherheit, Techniker, Labor und Zertifikatsmetadaten bereit.
- **Kalibrierverfahren** — stellt Variablen zu Ausrüstung, Verfahrensmetadaten,
  Umgebungsbedingungen, Schritten, Abnahmekriterien, Sicherheitshinweisen, Techniker, Genehmigung
  und Revisionshistorie bereit.

Beim Bearbeiten werden nur die für den Vorlagentyp relevanten Variablen angezeigt.

## Das Editor-Layout

Der Editor ist ein dreispaltiges Desktop-Layout, keine scrollende Webseite — das mittlere Panel
stellt das Dokument als physische A4- (oder Letter-)Seite dar, im selben Verhältnis, in dem es
später gedruckt wird.

- **Werkzeuge** (links) — klicken oder ziehen Sie ein Element auf die Seite, um es einzufügen:
  Text (Überschrift, Absatz, horizontale Linie, Seitenumbruch), Daten (Variable, Tabelle,
  Messwerttabelle, Schlüssel/Wert-Feld), Technisch (Gleichung, Diagramm,
  Kalibrierdatendiagramm, Bild, QR-Code, Unterschrift, Datum, Seitenzahl) und Layout (Spalten,
  Abstandhalter, Abschnitt, Kopfzeile, Fußzeile).
- **Seitenfläche** (Mitte) — klicken Sie auf beliebigen Text, um ihn direkt zu bearbeiten; eine
  kontextabhängige Formatierungsleiste (Schriftart, Größe, Fett/Kursiv/Unterstrichen,
  Ausrichtung, Farbe, Hervorhebung, Zeilen-/Absatzabstand, Listen) erscheint über der Seite,
  solange ein Textblock ausgewählt ist. Die strukturierten Eigenschaften eines Blocks selbst (die
  Zeilen/Spalten einer Tabelle, die Achsen eines Diagramms, der Inhalt eines QR-Codes, …) werden
  im Tab **Block** rechts bearbeitet.
- **Variablen** (rechts) — durchsuchen oder durchstöbern Sie jede für den Vorlagentyp verfügbare
  Variable, gruppiert nach Kategorie (Anlage, Kalibrierung, Kalibrierergebnisse, Messwerte,
  Organisation, Benutzer/Techniker, Daten, …). Ein Klick fügt sie in den ausgewählten Textblock
  ein oder hängt einen neuen Absatz an, wenn nichts ausgewählt ist. Eine Sammlungsvariable (z. B.
  Messwerte) wird getrennt von skalaren Variablen angezeigt und kann als fertige, sich
  wiederholende Tabelle eingefügt werden.

## Vorlagen- vs. Vorschaudaten-Modus

Wechseln Sie zwischen dem Modus **Vorlage** — der die rohen `{{ variable }}`-Platzhalter zeigt —
und dem Modus **Vorschaudaten**, der jeden Platzhalter durch realistische Beispielwerte ersetzt
(z. B. `{{asset.id}}` → `OG-000123`), damit Sie ungefähr sehen können, wie ein erzeugtes Dokument
aussehen wird, bevor überhaupt eine echte Kalibrierung existiert. Eine an eine Sammlungsvariable
gebundene, sich wiederholende Tabelle rendert im Vorschaumodus eine Beispielzeile pro
Beispieldatenpunkt.

## Das Dokumentmodell

Der Inhalt einer Vorlage wird als strukturiertes JSON gespeichert — ein Array typisierter
**Blöcke** (`heading`, `table`, `equation`, `qr_code`, …), jeder mit eigenen Eigenschaften —
niemals als HTML-String. Das hält die Ausgabe des Editors reproduzierbar für einen künftigen
serverseitigen PDF-Renderer, der denselben Blockbaum durchläuft, den der Browser zeichnet,
anstatt beliebiges HTML/CSS neu interpretieren zu müssen.

Seitenlayout (Größe, Ausrichtung, Ränder, Standardtypografie) sowie die sich wiederholende
Kopf-/Fußzeile sind dokumentweite Einstellungen, die im Tab **Dokument** rechts bearbeitet werden
— der Inhalt von Kopf- und Fußzeile wiederholt sich auf jeder Seite eines erzeugten PDFs.

## Versionierung und Veröffentlichung

Der Verlauf einer Vorlage funktioniert wie der Kalibrierverlauf: **unveränderlich und
nachvollziehbar**.

- Eine neue Vorlage beginnt als **Version 1, Entwurf** — bearbeitbar, während der Arbeit
  automatisch gespeichert.
- **Veröffentlichen** friert diese Version ein. Eine veröffentlichte Vorlage kann nicht mehr
  direkt bearbeitet werden — sie wurde möglicherweise bereits zur Erzeugung echter Zertifikate
  verwendet.
- Das Bearbeiten einer veröffentlichten Vorlage verzweigt eine neue **Entwurfs**-Version
  (Version + 1) innerhalb derselben Vorlagengruppe; das Veröffentlichen dieses Entwurfs löst die
  vorherige Version ab. Existiert bereits ein Entwurf, öffnet erneutes Bearbeiten denselben
  Entwurf wieder, statt einen weiteren zu erstellen.
- **Duplizieren** erstellt stattdessen eine völlig neue, unabhängige Vorlage (mit eigener
  Versionshistorie), vorausgefüllt mit dem Inhalt der Quellversion — um eine Variante zu
  beginnen, statt dieselbe fortzusetzen.
- **Archivieren** blendet eine Vorlage aus der Standardliste aus, ohne ihre Historie zu löschen.

## Bilder

Bilder (ein Firmenlogo, ein Akkreditierungszeichen, ein Diagramm) werden pro Vorlage hochgeladen
und als Dateiverweise gespeichert — ein Bildblock enthält eine `file_id` und eine aufgelöste
Vorschau-URL, keine eingebettete Kopie der Datei-Bytes.

## Export und Import

Eine Vorlage kann in eine portable JSON-Datei exportiert (ihr Name, Beschreibung, Typ und
vollständiges Dokument) und anderswo wieder importiert werden — als neuer Entwurf mit eigener,
unabhängiger Versionshistorie — über **„Neue Vorlage" → „JSON-Vorlage importieren"**. Wie bei der
LaTeX-Import-Option zeigt das Modal eine Live-Vorschau der ausgewählten Datei und erlaubt es, vor
dem Erstellen des Entwurfs den Namen und die Start-Versionsnummer zu überschreiben. Anders als
ein roher `.tex`-Upload durchläuft eine exportierte Vorlage denselben Editor hin und zurück:
importieren, weiter bearbeiten, veröffentlichen. Es ist kein LaTeX — das wird automatisch beim
PDF-Zeitpunkt erzeugt (siehe unten), nicht etwas, das Sie selbst verfassen oder austauschen.

## PDF-Erzeugung

Eine **veröffentlichte** Editor-Vorlage kann einen echten Kalibrierbericht als PDF erzeugen,
genau wie eine hochgeladene `.tex`-Zertifikatsvorlage. Intern wird das strukturierte JSON-Dokument
der Vorlage in LaTeX umgewandelt und mit derselben
[Tectonic](../calibration/certificate-templates.mdx)-Pipeline kompiliert — keine separate
PDF-Engine, keine separaten Escape-Regeln zu lernen. Gleichungsblöcke enthalten bereits rohes
LaTeX und werden direkt durchgereicht; alle anderen Blöcke (Text, Tabellen, wiederholende Zeilen
gebunden an eine Sammlung, Diagramme, QR-Codes, Spalten, …) werden automatisch übersetzt.

Diese Auflösung gilt nur für Vorlagen vom Typ **Kalibrierzertifikat** — eine
Kalibrierverfahren-Vorlage ist ein statisches Referenzdokument, kein pro Kalibrierung erzeugtes.

### Einem Kanal eine Standardvorlage zuweisen

Öffnen Sie den Editor eines Sensorkanals (**Anlagen → eine Anlage → Übersicht → Bearbeiten**) und
setzen Sie **Standard-Berichtsvorlage** auf eine beliebige veröffentlichte Vorlage, beider Art
(hochgeladenes `.tex` oder im Editor erstellt). Jede an diesem Kanal erfasste Kalibrierung
verwendet sie, sofern nicht einzeln überschrieben (siehe unten). Lassen Sie das Feld leer, um auf
den Standard der Organisation zurückzugreifen, dann den globalen Standard, dann die integrierte
Vorlage — dieselbe Kette, die [Zertifikatsvorlagen](../calibration/certificate-templates.mdx)
bereits verwenden.

### Die Vorlage für eine Kalibrierung überschreiben

Auf der Detailseite einer Kalibrierung erlaubt das Chevron-Menü der Schaltfläche
**Herunterladen** einem Nutzer mit Bearbeitungsrechten (jede Rolle oberhalb von Betrachter), eine
bestimmte Vorlage nur für diese Kalibrierung zu wählen — diese Wahl wird **dauerhaft
gespeichert**, kein einmaliges Rendering: Sie wird zu dem, was *alle* Nutzer künftig für diese
Kalibrierung herunterladen, bis sie erneut geändert oder auf "Standardvorlage" zurückgesetzt
wird. Ein Betrachter sieht dieses Menü nie — er erhält stets die Vorlage, die sich aus
Überschreibung, Kanal-Standard oder Organisations-/globalem Fallback ergibt, ohne eigene Wahl.
