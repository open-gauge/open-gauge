## Nomenclature centrale (GUM / VIM)

L'interface d'Open Gauge, les noms de champs de l'API, et le langage des certificats utilisent
ces termes avec précision — ce ne sont pas des synonymes interchangeables.

| Terme | Symbole | Définition |
|---|---|---|
| Mesurande | $Y$ | La grandeur particulière soumise au mesurage. |
| Grandeurs d'entrée | $X_1, \ldots, X_N$ | Grandeurs dont dépend le mesurande : $Y = f(X_1, \ldots, X_N)$. |
| Estimation de sortie | $y$ | Le résultat de mesure calculé, $y = f(x_1, \ldots, x_N)$. |
| Incertitude-type | $u(x_i)$ | Incertitude d'un résultat exprimée sous forme d'un écart-type. |
| Évaluation de Type A | — | Incertitude évaluée par analyse statistique d'une série d'observations (par ex. répétabilité des résidus de points de calibration). |
| Évaluation de Type B | — | Incertitude évaluée par tout autre moyen : spécifications du fabricant, certificats de calibration, données d'ouvrages de référence, résolution, jugement. Type A/B est une classification de la *méthode d'évaluation*, pas une distinction entre erreur « aléatoire » et « systématique » — le GUM déconseille explicitement le terme « incertitude systématique ». |
| Incertitude-type composée | $u_c(y)$ | Incertitude-type d'un résultat dérivée de plusieurs autres grandeurs — la racine carrée positive d'une somme de termes de variance/covariance pondérés par la sensibilité. |
| Incertitude élargie | $U$ | $U = k \cdot u_c(y)$. Définit un intervalle censé englober une fraction déclarée des valeurs raisonnablement attribuables au mesurande. |
| Facteur d'élargissement | $k$ | Multiplicateur numérique appliqué à $u_c(y)$ pour obtenir $U$. Doit toujours être déclaré aux côtés de $U$. |
| Coefficient de sensibilité | $c_i = \partial f/\partial x_i$ | Décrit comment $y$ varie avec un petit changement de $x_i$. |
| Degrés de liberté | $\nu$ | Indicateur de fiabilité d'une estimation d'incertitude-type (par ex. $\nu = n-1$ pour une moyenne de $n$ observations, $\nu = n-m$ pour un ajustement par moindres carrés à $m$ paramètres). |
| Coefficient de corrélation | $r(x_i, x_j)$ | $r = u(x_i, x_j) / [u(x_i)u(x_j)]$, borné $[-1, 1]$. |
| Correction | — | Une valeur ajoutée, ou un facteur appliqué, pour compenser un effet systématique *reconnu*. Le GUM suppose que toutes ces corrections sont appliquées **avant** l'évaluation de l'incertitude. |
| Traçabilité métrologique | — | (VIM, via l'ISO/IEC Guide 99) « Property of a measurement result whereby the result can be related to a reference through a documented unbroken chain of calibrations, each contributing to the measurement uncertainty. » Voir [la chaîne de traçabilité](../compliance/iso-17025.mdx#traceability-chain). |
| Vérification | — | (VIM, via l'ISO/IEC Guide 99:2007, 2.44) « Provision of objective evidence that a given item fulfils specified requirements. » Distincte de la *calibration* — la vérification est une vérification réussite/échec par rapport à une exigence ; la calibration établit la relation entre l'indication et la valeur de référence. |
| Règle de décision | — | (ISO/IEC 17025, 3.7) « Rule that describes how measurement uncertainty is accounted for when stating conformity with a specified requirement. » Voir [Règles de décision](../calibration/decision-rules.mdx). |

### Erreur ≠ Incertitude

L'**erreur** est une grandeur idéalisée et inconnaissable (résultat − valeur vraie).
L'**incertitude** est un paramètre *positif* caractérisant la dispersion des valeurs
raisonnablement attribuables au mesurande. Les noms de champs d'Open Gauge (`max_error`,
`combined_uncertainty`, `expanded_uncertainty`) sont choisis pour être cohérents avec cette
distinction — `max_error` est une erreur évaluée à partir de données réelles, tandis que les
champs d'incertitude décrivent le *doute* autour d'un résultat, pas le résultat lui-même.
